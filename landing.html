05 · Safety

Fast is easy. Safe is the feature.

↩️

Revert in one command

Deleting user.js does not undo prefs — they persist in prefs.js. So ZenFox restores your backup, or you Refresh Firefox. No trap doors.

🔒

Security kept on

Fullscreen spoofing warnings stay safe. The unsafe 0/-1 combo is a labeled opt-in only. Localhost is never blocked.

📏

No fairy-tale numbers

No rig, no "2x faster" claims. The method (Speedometer, cold start, 4K drops) is published — bring hardware, fill the table.

06 · FAQ

Asked, answered.

Will this break my Firefox?
Balanced defaults are chosen to not break sites. AdvancedFox strong can — run --dry-run compare first. Every install backs up.
How do I uninstall?
Restore your zenfox-backup-* folder, or about:support → Refresh Firefox. Deleting user.js alone is not enough — prefs persist in prefs.js.
Which files do I need?
user.js alone is complete. Add LiteFox.js for debloat, Softfox.js ZEN for scroll. policies.json goes to Firefox distribution/, never the profile.
Does it phone home?
No. Both presets install offline from local files. Downloads happen only with an explicit hash-pinned --adv-url.
Flatpak / Snap / fresh profile?
Both auto-detected. No profile? GUI offers Create new, or python3 setup.py --preset zenfox --create-profile work --yes.
