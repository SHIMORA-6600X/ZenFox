About the Presets

Why SHIMORA?

SHIMORA is a careful engineering effort around Firefox configuration. Instead of hunting through hundreds of about:config entries, you drop in one file and get a browser that feels dramatically faster.

ZenFox keeps things simple: performance only.
AdvancedFox is for power users who also want privacy and hardening.

  • ✓ Network & rendering optimizations
  • ✓ Aggressive but safe cache tuning
  • ✓ Lower memory footprint under load
  • ✓ Optional hardening & privacy options
  • ✓ MIT licensed & fully open source

Installation

Up and running in 6 steps

⚠️ Works the same for both presets — just swap the file you drop in.

1

Create a backup profile

Always keep a safe copy of your current Firefox profile before applying any config.

2

Download ZenFox.zip or AdvancedFox.zip

Grab the latest release from GitHub Releases — not the source archive.

3

Review overrides

Check Common Overrides and Optional Hardening and tweak anything you don't want.

4

Open Firefox profiles page

Type about:profiles in the URL bar and press Enter.

5

Open the profile root folder

For your target profile, click Open Folder next to Root Directory.

6

Move user.js into the folder

Restart Firefox — enjoy the speed boost.
