About the Project

Why SwiftFox?

SwiftFox is a careful engineering effort around Firefox configuration. Instead of hunting through hundreds of about:config entries, you drop in one file and get a browser that feels dramatically faster.

Litefox.js for debloating.

Installation

Up and running in 6 steps

⚠️ Back up your profile first — you can always undo by deleting user.js.

1

Create a backup profile

Open Firefox → about:profiles → Open Folder next to Profile in use → copy that folder somewhere safe.

2

Download SwiftFox.zip

Grab the latest release from GitHub Releases — not the source archive.

3

Pick your file

Extract the zip and choose swiftfox.js, litefox.js or softfox.js.

4

Close Firefox & open profiles

Fully close Firefox, reopen it, then type about:profiles in the URL bar.

5

Open the profile root folder

For your target profile, click Open Folder next to Root Directory.

6

Rename to user.js & copy it in

Rename the chosen file to exactly user.js, copy it into the folder, and restart Firefox. Done.
