Three things I refuse to compromise.

Every project gets judged against the same bar: does it run fast, can anyone inspect it, and does it respect the person using it.

F.01

Performance is a feature

Slow software is broken software. I profile, trim, and tune until tools feel instant — starting with the browser, where most days are spent.

F.02

Open by default

If it can't be read, forked, and fixed by a stranger, it isn't finished. Public repos, permissive habits, documented configs.

F.03

Privacy is the baseline

No trackers, no dark patterns, minimal data. Replacements for closed tools are chosen the way a lock is chosen — by what they keep out.

F.04

Learn in the open

Notes, dotfiles, and experiments ship publicly — half-finished included — so the next person starts further along.

One flagship, a growing shelf.

Small surface area, maintained with care. ZenFox leads; the rest support the same mission.
