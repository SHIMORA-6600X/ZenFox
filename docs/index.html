⚙️ Installation (60 Seconds)

1
Create a Backup Profile: Always backup before making changes to avoid losing profile data.
2
Download user.js: Get the file from the Releases section (Right click > Save Link As…).
3
Review Settings: Check Common Overrides and Optional Hardening to match your preferences.
4
Open Firefox Profiles: Type about:profiles in the URL bar and press Enter.
5
Open Profile Folder: Click "Open Folder" in the Root Directory section of your active profile.
6
Move the File: Place the user.js file into the folder. Restart Firefox and enjoy!
⚠️ Important: Download ZenFox.zip from the Releases page, not the source code from the main page.
